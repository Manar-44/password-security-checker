
# Password Security Checker

## Project Description
A Python program that evaluates password strength, provides a security score, and suggests improvements.

## Planned Features
- Check password length.
- Check for uppercase and lowercase letters.
- Check for numbers.
- Check for special characters.
- Provide a password strength score out of 5.
- Provide suggestions to improve password strength.
