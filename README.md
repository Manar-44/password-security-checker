# Password Security Checker

## Description
A simple Python program that checks password strength,
gives a score out of 5, and suggests ways to improve it.

## Features
- Check password length (at least 15 characters).
- Check for uppercase and lowercase letters.
- Check for numbers and special characters.
- Calculate the password score.
- Display password strength (Weak, Medium, or Strong).
- Suggest improvements based on missing requirements.

## Technologies
- Python
- Git
- GitHub

## Example Output

```text
Enter your password: apple123

Password strength: Weak
Score: 2/5

Suggestions:
- Increase password length
- Consider adding uppercase letters
- Consider adding special characters
```

## Limitations
This project uses a basic scoring system and does not
guarantee that a password is secure. Use sample passwords
instead of real passwords.
